1. **バンドサークルLyrical の停止歴**: 2022年12月に無期限活動停止命令が発令されたが、2025年度公認学生団体一覧（2025/7/1付）に独立団体として掲載されているため、公認は維持されている（もしくは正式に復帰済み）と判断。DB登録は問題ないが、アプリ運営上のリスク管理として把握しておくことを推奨。

2. **日本コリア交流サークルの公認確定**: 複数の二次ソース（塾生情報局）では「未公認」と記載されていたが、2025年度公認学生団体一覧PDFでの直接確認により「独立団体」と確定。旧情報を上書きすること。

3. **日仏学生会 SNS**: Instagram・X のアカウントを複数の検索で確認できなかった。DB登録の際は SNS フィールドを NULL とし、Facebook ページ（https://www.facebook.com/ofj.info/）の記載のみに留めるか、追加調査後に更新推奨。

4. **総合音楽研究会 Instagram**: 年度ごとに新歓アカウント名が変わる（@sok_2025 → @sok_2026）。メインアカウントは @sok.orien の可能性あるが確定ではない。DB登録前に最新アカウントを再確認推奨。

5. **設立年不明の4件**: バンドサークルLyrical、オフコース・ミュージック・カンパニー、日仏学生会、日本コリア交流サークルについては設立年をウェブ検索・公式サイトから確認できなかった。DB登録時は設立年フィールドを NULL または「不明」とする。
