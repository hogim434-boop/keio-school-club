## 1. KPOP完コピダンスサークルNAVI

### 基本情報

| 項目               | 内容                                 |
| ------------------ | ------------------------------------ |
| 正式名称（日本語） | KPOP完コピダンスサークルNAVI         |
| 創立年             | 2015年                               |

| 主活動キャンパス   | 日吉キャンパス（協生館、貸スタジオ） |

### 活動内容

K-POPアイドルのダンスを衣装・メイク・表情・角度・癖にいたるまで完全に再現する「完コピ」スタイルのカバーダンスサークル。技術の高さよりも「アイドル本人への似せ方」を最重視しており、ステージ動画や練習動画を繰り返し分析して細部まで研究する。

**年間主要イベント**

- 4〜6月：新歓合宿・新入生発表会
- 8〜9月：夏合宿・早慶上智交流会
- 10月：ハロウィンパーティー
- 11月：三田祭ステージ本番
- 12月：全国大会「ユニ♡KP」出場・クリスマスパーティー

衣装制作、MV制作、SNS運用、宣材写真撮影なども活動の一環として行う。

### 主要実績・特徴（3点）

1. **慶應義塾大学唯一のK-POP完コピカバーダンスサークル**。全国K-POPカバーダンス大会「ユニ♡KP」に継続出場。
2. **約160〜200名規模**の大型サークル。メンバーの10〜20%が韓国・中国などからの留学生で国際色が強い。全体の60〜70%が入会時ダンス初心者。
3. 三田祭での**ステージパフォーマンスを毎年開催**。新大久保の公開ステージにも有志で出演実績あり。

## 2. Revolve（慶應義塾大学公認ストリートダンスサークルRevolve）

### 基本情報

| 項目               | 内容                                            |
| ------------------ | ----------------------------------------------- |
| 正式名称（日本語） | 慶應義塾大学公認ストリートダンスサークルRevolve |
| 創立年             | 2001年                                          |
| 分類               | 慶應義塾大学公認学生団体（独立団体）            |
| 主活動キャンパス   | 日吉キャンパス（協生館地下スペース・集会室）    |

### 活動内容

創立者が「ダンス一緒にやりませんか？」というメッセージを学内で配信して2001年に発足。当初はブレイクダンス中心だったが、現在は以下の9ジャンルを展開。複数ジャンルの掛け持ちも可能。

**対応ジャンル（9種類）**

| ジャンル          | 概要                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| BREAK             | 1970年代NYC発祥。フットワーク・アクロバット・フリーズ。Revolveの原点 |
| POP               | 筋肉を弾く動き。ヒットやウェーブが特徴                               |
| LOCK              | LA発祥。激しい動きから突然静止してポーズ                             |
| MIDDLE HIPHOP     | 深いダウンで重くグルーブする                                         |
| NEW SCHOOL HIPHOP | R&B等を取り込み常に進化するジャンル                                  |
| GIRLS HIPHOP      | 腰や胸を使う女性らしい動き                                           |
| HOUSE             | 流れるような素早いステップとフロアワーク                             |
| WAACK             | 1970年代ゲイクラブ発祥。腕をしならせる技法                           |
| JAZZ              | バレエ基調。体全体を使った表現                                       |

**年間主要イベント**  
三田祭ダンスショー（最大イベント、直前は連日練習）、矢上祭、年3回程度のクラブ貸し切りイベント、夏・冬合宿。

### 主要実績・特徴（3点）

1. **慶應義塾大学最大規模のダンスサークル**（約600名）。9ジャンル体制で国内最大級の学生ダンス団体の一つ。
2. **毎年約8割が入会時ダンス初心者**。「踊りたい人が、踊りたいときに、踊れる」をコンセプトとし、強制参加なし。
3. 三田祭での**大規模ダンスショーを創立以来継続開催**。「ダンスをやってみたい」という動機で入会できる敷居の低さが特徴。

## 3. チア＆ソングリーダーズUNICORNS

### ⚠️ 注記：団体構造と体育会移行

「チア＆ソングリーダーズUNICORNS」は**チアリーディング部門**と**ソングリーディング部門**の2部門で構成される。  
Circle Square 2026では両部門ともに「**體育會所属団体**」と明記されており、**2026年度から体育会へ移行**した。  
2025年度以前は**独立団体**として公認。各部門はInstagramアカウントを別々に保有。

### 基本情報

| 項目               | 内容                                                                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 正式名称（日本語） | チア＆ソングリーダーズUNICORNS                                                                                                      |
| 創立年             | 推定1994年 ※チアリーディング部門。YouTubeハンドル @unicco1994、2025年度の32期在籍より逆算。ソングリーディング部門の個別創立年は不明 |
| 分類               | 2025年度まで独立団体、2026年度より體育會所属団体                                                                                    |
| 主活動場所         | 世田谷区・港区体育館、横浜市運動センター、新木場BumB東京スポーツ文化館、日吉キャンパス、SFCキャンパス                               |

### 活動内容

**チアリーディング部門**  
競技チアリーディング（タンブリング・スタント・アクロバット技）。関東大会・全日本学生選手権に出場。学園祭演技、体育会ラグビー部ハーフタイムショー、早慶戦応援演技、結婚式や東京タワーでの外部演技。

**ソングリーディング部門**  
競技ソングリーディング（チアダンス形式：Pom / Funk / Jazz）。アームモーション・ジャンプ・ターン・ラインダンスで構成される競技演技。JCDA大会・USA大会等全国大会出場。七夕祭・三田祭出演。年1回（7月頃）の自主公演開催。

### 主要実績・特徴（3点）

1. **ソングリーディング部門：全日本学生チアダンス選手権 Pom部門 2019年・2022年優勝**、USA Nationals 2021年・2022年第3位。
2. **慶應学内唯一のチアリーディング・ソングリーディングチーム**。男子・他性別は在籍なし（女性のみ）、兼サー率5%と専念度が高い。
3. **週5日の正規練習体制**（月〜土の授業後または終日）。大会シーズンは強度が上がる。

## 4. 津軽三味線集団 弦音巴（おとは）

### ⚠️ 名称読み方の訂正

**正しい読み：おとは（OTOHA）**  
「げんおんは」ではない。複数の出典（YouTube動画タイトル、CAMPFIREプロジェクト文、公式ドメイン `otohakeio.wixsite.com`）で「おとは」と確認済み。

### 基本情報

| 項目               | 内容                                  |
| ------------------ | ------------------------------------- |
| 正式名称（日本語） | 津軽三味線集団 弦音巴（よみ：おとは） |
| 創立年             | 2015年                                |
| 分類               | 慶應義塾大学公認学生団体（独立団体）  |
| 主活動キャンパス   | 日吉キャンパス（詳細場所は不明）      |

### 活動内容

津軽三味線を演奏するサークル。「津軽三味線の魅力を幅広い世代、そして国や地域に広める」をミッションとする。ロック系現代曲から伝統民謡まで幅広いレパートリーで活動。

**活動・出演先の例**

- 定期演奏会（単独公演）の開催
- 三田祭等の学内学園祭
- ホテル・ディズニー施設・高齢者施設での演奏
- ASEAN地域向けオンライン配信（海外）
- 老人ホーム25箇所同時オンライン中継実績
- 津軽三味線全国・世界大会への出場

**特筆事項：** 部員のほぼ全員が大学入学後に三味線を始める初心者歓迎サークル。

### 主要実績・特徴（3点）

1. **2018年 津軽三味線世界大会（弘前）グループA部門 準優勝**。全国大会でも複数回準優勝。弘前世界大会で金賞受賞実績あり。
2. **大学入学後の初心者が主体**でありながら世界大会出場レベルに到達。創立10年で国内外大会を席巻する異色の実績。
3. **海外オンライン演奏・ASEAN配信**など活動範囲が国際的。老人ホームへの訪問演奏など社会活動にも積極的。

## 5. アカペラシンガーズK.O.E.（A Cappella Singers K.O.E.）

### 基本情報

| 項目               | 内容                                                               |
| ------------------ | ------------------------------------------------------------------ |
| 正式名称（日本語） | アカペラシンガーズK.O.E.（英語正式名：A Cappella Singers K.O.E.®） |
| 創立年             | 1995年（2025年度で31年目）                                         |
| 分類               | 慶應義塾大学公認学生団体（独立団体）                               |
| 主活動キャンパス   | 慶應義塾大学 湘南藤沢キャンパス（SFC）                             |

### 活動内容

「声だけを楽器とする」アカペラパフォーマンス専門サークル。SFC唯一のアカペラサークルとして31年間活動を継続。

**組織構造**

- 4〜7名の小編成バンドが複数組成され、各バンドが自主的に練習・曲選び
- 全員参加の全体曲（大人数での厚みある演奏）も実施
- 毎週火曜日放課後にSFCで全体会（定例ミーティング + 合同練習）

**音楽以外の担当業務**  
音響・照明オペレーション、ロゴマーク・チラシデザイン、映像・BGM制作 など。ミュージカルアカペラも行う。

**主要イベント**

- K.O.E. CONCERT（年2回：夏・冬の自主コンサート）
- 合宿（年2回）
- SFC学内イベント出演
- 有志バンドによる全国大会出場

### 主要実績・特徴（3点）

1. **著名OGに歌手・一青窈（いちご ようこ）が在籍**（元メンバーとして広く知られる）。
2. **YouTubeチャンネル「ケビンズイングリッシュルーム」**（登録者数多数のエンタメYouTuber）のメンバーが学生時代に在籍。
3. **SFC唯一のアカペラサークル**として31年間継続。声のみで音響・照明・制作まで手掛けるセルフプロデュース体制。
