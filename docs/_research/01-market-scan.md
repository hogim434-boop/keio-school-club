## 1. 소모임 (韓, somoim.co.kr)

### 핵심 기능
1. **소모임(동호회) 개설 및 탐색** — 카테고리·위치 기반 취미 모임 검색 및 가입 (1인당 최대 7개)
2. **정모 / 번개 개설** — 정기모임과 즉석 모임을 별도 타입으로 운영, 위치 기반 자동 추천
3. **단체 채팅** — @멘션, 태그메시지(1:1 알림), 단체방; 운영진별 권한 제어
4. **게시판 + 사진첩** — 모임 전용 피드, 앨범 기능으로 활동 아카이브
5. **운영진 권한** — 모임장·부운영자 임명, 멤버 승인, 유료 프리미엄 모임 운영

### 채팅 구현 방식
- 모임별 단체 채팅방 자동 생성
- @태그로 특정 멤버에게 1:1 알림 발송
- 운영진 공지 채널 별도 운영

### 캘린더 구현 방식
- 정모/번개 리스트 형식(날짜·시간·장소 표시)
- 거주지/직장 위치 기반 오늘의 정모 상단 추천
- 앱 내 캘린더 뷰는 없음 — 리스트 + 지도 중심

### 이벤트 참가 신청 구현 방식
- 모임 가입 후 정모 참석 버튼으로 원클릭 신청
- 유료 프리미엄 모임은 결제 연동(월·연 구독)
- 참석자 수 공개로 사회적 증명 형성

### 모바일 UX 특징
- 하단탭: 홈(추천) / 탐색 / 내 모임 / 알림 / 마이페이지 5탭 구성
- 위치 기반 오늘의 모임 카드가 홈 상단 배치
- 취미 카테고리 아이콘 그리드로 빠른 탐색

### K CLUB이 차용할 포인트
1. **정모/번개 이원화** — 정기 활동과 즉석 이벤트를 별도 생성 플로우로 분리
2. **운영진 권한 계층** — 모임장·부운영자·일반 멤버 3단계 권한으로 관리 부담 분산
3. **위치 기반 당일 이벤트 추천** — 캠퍼스 위치 기반으로 오늘 열리는 サークル・部活動 이벤트 홈 노출

## 2. Lu.ma (글로벌, lu.ma)

### 핵심 기능
1. **이벤트 페이지 빌더** — 2분 이내 아름다운 이벤트 페이지 생성, 싱글 스크린 폼
2. **RSVP + 티켓 판매** — Stripe 연동 유료 티켓, 무료 RSVP 통합; 익일 정산
3. **QR 체크인** — 현장 입장 시 QR 스캔 or 이름/이메일 검색
4. **Blast 메시지** — 게스트 전체 또는 세그먼트에 이메일/알림 예약 발송
5. **캘린더 통합** — Google/Apple 캘린더 자동 추가, Zoom/Meet 자동 생성

### 채팅 구현 방식
- 채팅 기능 없음 — 호스트→게스트 일방 소통(Blast 메시지)
- 이벤트 후 피드백 수집 기능 별도

### 캘린더 구현 방식
- 이벤트 생성 시 Google/Apple 캘린더 초대 링크 자동 생성
- 가상 이벤트는 Zoom 링크 자동 매립
- 호스트 대시보드에 일정 타임라인 뷰 제공

### 이벤트 참가 신청 구현 방식
- 링크 공유 → 이메일 입력만으로 즉시 RSVP (계정 없이도 가능)
- 승인 필요(Approval Required) 모드로 게이팅 가능
- 토큰 게이팅(NFT/암호화폐 보유자 전용) 지원

### 모바일 UX 특징
- 이벤트 생성이 단일 스크롤 화면(폼 분리 없음)
- 이벤트 카드 디자인 중심 — 커버 이미지 16:9 강조
- 호스트 대시보드는 웹 중심, 모바일은 게스트 뷰 최적화

### K CLUB이 차용할 포인트
1. **단일 화면 이벤트 생성 플로우** — 단계 분리 없는 싱글 스크롤 생성 UX로 진입 장벽 최소화
2. **RSVP 승인 게이팅** — 동아리 비공개 이벤트에 운영진 승인 후 참가 확정 플로우 적용
3. **Blast 메시지** — 참가자 전체에게 이벤트 전날 리마인더 일괄 발송 기능

## 3. Geneva (글로벌, geneva.com)

### 핵심 기능
1. **Home + Rooms 구조** — 커뮤니티(Home)를 주제별 Room으로 분리; Discord와 유사하나 더 경량
2. **5가지 Room 타입** — 채팅방 / 포스트방 / 오디오방 / 비디오방(최대 16인) / 브로드캐스트방
3. **이벤트 초대 + 캘린더** — 내장 이벤트 인바이트와 통합 캘린더로 RSVP + 리마인더
4. **역할 기반 권한** — 초대, 방 생성, 메시지 중재 등을 역할별 세분화
5. **입장 심사** — 가입 전 설문(questionnaire)으로 멤버 검증

### 채팅 구현 방식
- 채팅 Room: @멘션, 스레드 답글, 반응, GIF, 첨부, 폴, 핀 지원
- 오디오/비디오 Room: 즉석 음성·화상 대화 공간
- 광고·데이터 판매 없음, 전화번호 인증으로 어뷰징 방지

### 캘린더 구현 방식
- Home 단위 통합 캘린더 내장
- 이벤트 등록 시 구성원 전체에 RSVP 알림 발송
- 리마인더 자동 발송

### 이벤트 참가 신청 구현 방식
- 이벤트 Room 또는 캘린더 내 이벤트 카드에서 RSVP
- 호스트가 참가자 명단 확인 가능

### 모바일 UX 특징
- 좌측 사이드바(홈 목록) + 우측 콘텐츠 영역 — 태블릿 감각의 2-패널 레이아웃
- 모바일에서는 스와이프로 홈↔Room 전환
- GenZ 여성 사용자층 중심, 소셜 앱 감성의 비주얼 디자인
- 팔로우 카운트, 좋아요 없는 "No-Like Zone" 철학

### K CLUB이 차용할 포인트
1. **Room 타입 다양화** — 공지 전용 방 / 일반 채팅방 / 행사 방을 목적별로 분리 운영
2. **가입 심사 설문** — 동아리 신입 가입 신청 시 운영진이 답변을 보고 승인하는 플로우
3. **통합 캘린더 내 RSVP** — 캘린더 뷰에서 바로 이벤트 참가 신청 가능한 인라인 UX

## 4. Partiful (글로벌, partiful.com)

### 핵심 기능
1. **초간단 이벤트 생성** — 제목/날짜/장소/테마 설정 후 링크 공유, 계정 불필요
2. **소셜 RSVP** — 참가 여부(Going/Maybe/Can't Go) 누르면 다른 참가자 목록 즉시 공개
3. **Boops(반응)** — 누군가 RSVP하면 다른 참가자가 반응(이모지) 가능 → 기대감 증폭
4. **SMS 기반 알림** — 이메일 불필요, 문자로 초대·리마인더·업데이트 수신
5. **비주얼 테마** — GenZ 취향의 애니메이션 배경, 팝컬처 테마 커스터마이징

### 채팅 구현 방식
- 채팅 없음 — 이벤트 댓글(코멘트 섹션)로 참가자 간 소통
- 호스트→참가자 공지 메시지 기능

### 캘린더 구현 방식
- 별도 캘린더 없음
- 이벤트 생성 후 Apple/Google 캘린더 추가 링크 제공

### 이벤트 참가 신청 구현 방식
- 링크 클릭 → 전화번호 입력 → Going/Maybe/Can't Go 선택 (3단계)
- 계정 없이 RSVP 완료, 이후 문자로 업데이트 수신
- 소셜 증명: RSVP 후 이미 간다는 친구 목록 바로 노출

### 모바일 UX 특징
- 웹 앱 + 네이티브 앱 병행
- 초대장이 곧 이벤트 페이지 — 별도 전환 없음
- 문자 메시지 채널로 계정/앱 설치 진입 장벽 완전 제거
- 500만+ MAU, 전년 대비 400% 성장 (2025 기준)

### K CLUB이 차용할 포인트
1. **소셜 참가자 목록 공개** — RSVP 후 누가 오는지 보여주는 소셜 증명으로 참가 동기 강화
2. **3클릭 참가 신청** — 계정 없이 링크→번호→Going으로 완결되는 최소 마찰 플로우
3. **Boops(반응) 개념** — 이벤트에 참가자가 늘어날수록 커뮤니티 반응(이모지/응원)으로 바이럴 효과

## 5. 일본 동아리 앱 — CircleApp(サークルアップ) + サークルスクエア

### 5-1. CircleApp / サークルアップ (circle-app.jp)

**개요:** 390개 대학, 4,500개 서클, 약 20,000명 재학생 커버

#### 핵심 기능
1. **메일링리스트형 일괄 메시지** — 서클 전체 공지를 메일리스처럼 발송
2. **이벤트·행사 캘린더** — 날짜 등록 + 출결 관리 통합
3. **기업 오퍼(포인트 연동)** — 설문·인터뷰 참여 시 서클 포인트 + 개인 포인트 지급
4. **앨범 + 커스텀 리액션** — 서클 전용 앨범, 커스텀 반응 버튼
5. **개인 메시지** — 멤버 간 DM 기능

#### K CLUB 차용 포인트
1. **대학 공식 연계** — 학교 인증 기반 가입으로 신뢰도·안전성 확보
2. **출결 관리와 캘린더 통합** — 이벤트 등록 → 출결 확인이 한 화면에서 처리
3. **서클 포인트 시스템** — 활동 참여 인센티브 구조 (장기적 고려)

### 5-2. サークルスクエア (c-sqr.net)

**개요:** 팀·단체·커뮤니티 운영 전용 그룹웨어

#### 핵심 기능
1. **채팅** — 멤버 제한 채팅룸, 이미지·리액션, 기존/신규 읽음 표시
2. **이벤트 캘린더 + 출결관리** — 정원 설정, 캔슬 대기, 지각/조퇴 세분화
3. **게시판 + 앙케트** — 공지 게시판, 설문조사 기능
4. **앨범 + 파일 공유** — 사진·파일 공유 전용 공간
5. **메일 배신** — 이메일 일괄 발송

#### K CLUB 차용 포인트
1. **정원 + 캔슬 대기 기능** — 인기 이벤트 정원 초과 시 대기 순번 자동 관리
2. **지각/조퇴 구분 출결** — 단순 참가/불참을 넘어 세분화된 출결 상태 관리
3. **채팅 + 캘린더 단일 앱 통합** — 별도 툴 없이 한 앱에서 소통~일정~참가 완결
