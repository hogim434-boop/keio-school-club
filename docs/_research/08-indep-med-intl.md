- **判定: ✅ 正規公認（学生総合センター）**

### 基本情報

| 項目             | 内容                                          |
| ---------------- | --------------------------------------------- |
| 正式名称(日本語) | 慶應義塾大学医学部国際医学研究会（通称：IMA） |
| 正式名称(英語)   | International Medical Association (IMA)       |

| 主活動キャンパス | 信濃町（医学部）                              |

### 活動内容

- 医学部6年生の夏休みを利用し、南米（主にブラジル）での医療活動・研究発表を実施
- アマゾン川流域での移動診療船活動、先住民族へのメディカルチェックアップ

### 紹介文用 実績・特徴3点

1. 創立45年以上の伝統。第48次派遣団（2025年）まで継続的に派遣を維持
2. 慶應義塾大学医学部公式特集記事（2022年6月）で活動が紹介された公式認定団体
3. コロナ禍（2020-21年）に渡航停止でも国内での新たな活動形式を開発し継続した実績

## 団体3: KOSMIC

### 公認検証

- **判定: ⚠️ センター・学部公認（要注意）— 国際センター（KISC）独自公認**
- 2025年度公認学生団体一覧PDF（全文検索）に「KOSMIC」の記載なし（掲載なし確認済み）
- 慶應義塾大学 国際センター公式ページ（ic.keio.ac.jp）が「国際センター公認の留学生支援団体」として掲載
- 国際センターページで「国際センターの学生スタッフとして活動する」と明記

### 公認分類の結論

**KOSMICは「慶應義塾大学国際センター（KISC）公認」であり、「学生総合センター公認」ではない。**

慶應の中でも「大学中央組織（学生総合センター）」ではなく「国際センターという部局」に帰属する公認を受けた特殊な位置付けの団体。アプリDBの登録可否・表示方法については、「部局公認」を許容するかどうかのポリシー判断が必要。

### 基本情報

| 項目             | 内容                                                              |
| ---------------- | ----------------------------------------------------------------- |
| 正式名称(日本語) | 慶應義塾大学国際センター塾生機構                                  |
| 正式名称(英語)   | Keio Organization of Student Members of the International Center  |
| 略称             | KOSMIC                                                            |
| 創立年度         | 推定1984年頃（不確実。第40回スピーチコンテスト=2024年からの逆算） |
| 主活動キャンパス | 日吉・三田                                                        |
| 所属区分         | 国際センター公認（学生総合センター管轄外）                        |

### 活動内容

- 協定校からの交換留学生へのサークル紹介・新入生オリエンテーション支援
- 歓迎会・日本語スピーチコンテスト（約40年の歴史）・送別会の企画運営
- グローバルラウンジでの留学生交流イベント（月4回程度）

### 紹介文用 実績・特徴3点

1. 慶應義塾大学唯一の大学公認国際交流学生組織（約400名のメンバー）
2. 留学生による日本語スピーチコンテストを40年以上主催し続ける（第41回=2025年12月開催済み）
3. 国際センターの「学生スタッフ」として正式位置付けされており、大学公式イベントにも参加
