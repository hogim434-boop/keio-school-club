# T-025: 이벤트 취소·재고지 동선

| 항목 | 내용 |
|---|---|
| **Phase** | 1-3 |
| **우선순위** | Med |
| **예상 소요** | 1.5일 |
| **의존성** | T-024 |
| **관련 기능 ID** | F049 |
| **PRD 참조** | PRD 5-4 F049 |

## 산출물

- `app/circles/[id]/events/[eventId]/cancel/route.ts` 또는 Server Action
- 이벤트 상세 상단 빨간 배너 컴포넌트

## 검증 기준

- 운영자가 「이벤트 취소」 클릭 → `events.cancelled_at = now()`, `cancellation_reason` 입력
- 신청자 전원에 즉시 통보 (앱 내 + 이메일)
- 이벤트 상세 상단에 「中止されました — 理由: ○○」 빨간 배너 표시
- 캘린더에서 취소 이벤트 숨김 (또는 회색 표시)

## 세부 작업

- [ ] 취소 다이얼로그 (사유 입력)
- [ ] Server Action — `events` UPDATE + 전원 알림
- [ ] 상세 페이지 배너 표시 (T-014 의 자리 채움)
- [ ] 캘린더 (T-019) 에 cancelled_at IS NOT NULL 처리

## 위험·주의사항

- ⚠️ **취소 후 복구 불가** — UI 에서 강조 카피 「この操作は取り消せません」.
- ⚠️ **알림 발송 Rate limit** — T-024 와 동일 배치.

## 테스트 체크리스트

- [ ] 취소 후 배너 표시
- [ ] 신청자 인박스에 통보
- [ ] 캘린더에서 회색/숨김
