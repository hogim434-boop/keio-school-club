# T-046: Apple Developer Program 등록 (사전 작업, 초보자 함정)

| 항목 | 내용 |
|---|---|
| **Phase** | 1.5 |
| **우선순위** | High (Phase 1.5 진입 전 미리 시작) |
| **예상 소요** | 1-3일 (본인 인증 대기) |
| **의존성** | — (Week 19 末부터 미리 시작) |
| **관련 기능 ID** | — |
| **PRD 참조** | PRD 9-7 · 12-3 「본인 인증 지연」 |

## 산출물

- 활성화된 Apple Developer 계정 ($99/년)
- 활성화된 Google Play Console ($25 평생)

## 검증 기준

- App Store Connect 로그인 가능
- Google Play Console 로그인 가능

## 세부 작업

- [ ] Apple ID 준비 (개발자 본인 명의)
- [ ] [Apple Developer Program 등록](https://developer.apple.com/programs/) ($99/년)
- [ ] 본인 인증 (1-3일 대기, 신분증·여권 사진)
- [ ] 결제 완료 → 계정 활성화 확인
- [ ] [Google Play Console](https://play.google.com/console) 등록 ($25 평생)
- [ ] 결제 + 약관 동의

## 위험·주의사항

- ⚠️ **본인 인증 지연** — Apple 측 검토 1-3일. **Week 19 末부터 미리 시작 권장**. 안 그러면 Phase 1.5 진입 지연.
- ⚠️ **계정 명의** — 학생 계정으로 가입 시 Universities Program 옵션 있음 (무료). 단 회사로 등록하려면 D-U-N-S 번호 필요.
- ⚠️ **결제 카드** — 해외 결제 가능 카드 필수. 일본 학생 카드 안 되는 경우 있음.

## 테스트 체크리스트

- [ ] Apple Developer 활성화 메일 수신
- [ ] App Store Connect 첫 로그인 성공
- [ ] Google Play Console 첫 로그인 성공
