# T-034: 平均応答時間 통계 표시

| 항목 | 내용 |
|---|---|
| **Phase** | 1-4 |
| **우선순위** | Low |
| **예상 소요** | 1일 |
| **의존성** | T-028 |
| **관련 기능 ID** | F057 |
| **PRD 참조** | PRD 5-5 F057 |

## 산출물

- DB 뷰 또는 함수 `avg_response_time(circle_id)`
- 동아리 상세·DM 발신 폼에 표시

## 검증 기준

- 「平均的に○日以内に返信」 카피 표시
- 자율 압박 (강제 X) — 「必ず○日以内に返信」 같은 강한 표현 금지
- 응답 없는 동아리 → 「データ収集中」 표시

## 세부 작업

- [ ] DB 뷰 — `inquiry_messages` 의 inquirer 발신 → circle_staff 응답까지 시간 집계
- [ ] AVG 계산 (최근 3개월)
- [ ] 동아리 상세에서 표시
- [ ] DM 발신 폼에 표시

## 위험·주의사항

- ⚠️ **데이터 부족** — Phase 1 출시 직후 DM 적음. 「データ収集中」 fallback.
- ⚠️ **카피 강도** [[avoid-koujin-wording]] — 「必ず」 같은 강제 표현 금지.

## 테스트 체크리스트

- [ ] 답변 있는 동아리 → 시간 표시
- [ ] 답변 없는 동아리 → 「データ収集中」
