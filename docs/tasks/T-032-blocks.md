## 산출물

- 인박스에서 검토자 차단 UI
- `user_blocks` 활용 RLS

## 검증 기준

- 운영진이 검토자 차단 → `user_blocks` INSERT (circle 한정)
- 차단된 검토자는 해당 동아리 DM 발신 불가
- T-027 의 발신 폼에서 차단 시 「現在お問い合わせを受け付けていません」 안내

## 세부 작업

- [ ] 인박스 스레드 메뉴 「このユーザーをブロック」
- [ ] `user_blocks` INSERT (blocker, blocked, circle_id)
- [ ] T-027 의 DM 발신 Server Action 안에서 차단 검증 → 거부
- [ ] 차단 해제 UI (운영진 관리 페이지)

## 위험·주의사항

- ⚠️ **차단 사유 기록** — `user_blocks` 에 사유 컬럼 추가 검토 (운영진 인수인계용). 현재 스키마는 PK 4개만.
- ⚠️ **양방향 차단** — 검토자도 운영진을 차단할 수 있나? Phase 1 은 운영진 → 검토자만.
