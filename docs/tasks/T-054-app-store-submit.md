## 산출물

- App Store 메타데이터 (일본어 메인, 한국어 보조)
- 심사 통과 → 출시

## 검증 기준 ⭐ M-StoreLaunch (iOS) 게이트

- 앱 이름·Subtitle·키워드 일본어
- 카테고리: Education / Social Networking (Secondary)
- 스크린샷 5장+ (6.7"·6.5"·5.5" + iPad)
- 앱 아이콘 1024×1024
- 「데이터 안전」 (App Privacy) 섹션 완성
- 심사 통과

## 세부 작업

- [ ] 앱 정보 — 이름 「K CLUB」 + Subtitle (예: 「慶應生のサークル·部活動 検討ツール」)
- [ ] 키워드 (게이오·サークル·部활동·동아리·新歓 등 일본어)
- [ ] 스크린샷 디바이스별 5장+ (메인 4탭 + 동아리 상세 + DM 등)
- [ ] App Privacy 섹션 — Supabase 가 수집하는 데이터 모두 신고
- [ ] **Apple 4.2 통과 점검** (PRD 9-7-5):
  - [ ] 푸시 알림 작동
  - [ ] 카메라 작동
  - [ ] 딥링크 작동
  - [ ] 스플래시·상태바
- [ ] 심사 제출
- [ ] 거절 시 사유 분석 + 재제출

## 위험·주의사항

- ⚠️ **Apple 4.2 「단순 웹뷰 거절」** — T-048·T-049·T-050 의 네이티브 통합이 모두 작동해야 통과. **반드시 TestFlight 에서 확인 후 제출**.
- ⚠️ **스크린샷 다국어** — 일본어 메인. 한국어 보조 (선택).
- ⚠️ **심사 거절 시 1-2주 추가** — 거절 사유 분석 → 보강 → 재제출. Phase 1.5 일정 여유 확보.
- ⚠️ **App Privacy 누락** — Supabase·Vercel Analytics 등 데이터 수집 모두 신고. 누락 시 거절.
