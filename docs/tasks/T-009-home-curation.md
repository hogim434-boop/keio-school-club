## 산출물

- `app/(tabs)/page.tsx` ホーム — Server Component
- 섹션 3개: 今週新歓 / 다가오는 이벤트 / 추천 동아리

## 검증 기준

- 시드 데이터에서 3개 섹션 모두 데이터 표시
- 「今週新歓」 섹션은 4월·10월 시즌에만 활성 (환경변수 또는 날짜 분기)
- 추천 동아리 카드 클릭 시 동아리 상세로 이동

## 세부 작업

- [ ] 「今週新歓」 큐레이션 섹션 — 시즌 분기 로직 (환경변수 `NEXT_PUBLIC_SHINKAN_SEASON` 또는 월 분기)
- [ ] 「다가오는 이벤트」 섹션 — `lib/supabase/queries/events-public.ts` 의 `getUpcomingEvents(limit=5)`
- [ ] 「あなたへのおすすめ」 추천 동아리 — Phase 2 는 룰 기반, Phase 1 은 카테고리 랜덤 또는 인기순
- [ ] 빈 상태 카피 일본어
- [ ] 각 섹션에 「もっと見る →」 링크

## 위험·주의사항

- ⚠️ **시즌 외 큐레이션 비활성** — 7월에 「今週新歓」 섹션이 비어 있으면 어색. 빈 섹션 자체를 안 그리도록 분기.
- ⚠️ **공개 캐싱 정합성** — `tags:["events:public"]` + 이벤트 수정 시 `revalidateTag` 호출 필수 (T-021 에서).
- ⚠️ **추천 룰 명시 X** — Phase 1 은 간단 룰 (카테고리 랜덤). F013 「あなたの興味」 는 Phase 2.

## 테스트 체크리스트

- [ ] 추천 동아리 클릭 → 상세 페이지 이동
