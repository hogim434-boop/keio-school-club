# T-039: 동아리 등록 동선 (누구나 등록 → owner 승인 대기)

| 항목 | 내용 |
|---|---|
| **Phase** | 1-5 |
| **우선순위** | Med |
| **예상 소요** | 1.5일 |
| **의존성** | T-037 |
| **관련 기능 ID** | F073 |
| **PRD 참조** | PRD 5-7 F073 |

## 산출물

- 동아리 등록 폼 페이지
- 승인 대기 상태 표시

## 검증 기준

- 인증된 사용자 누구나 등록 가능
- 등록 직후 `circle_members.role='owner', approved_by_admin=false`
- 승인 대기 중에는 owner 권한 미부여 (DM 답변 불가)
- 승인 후 자동으로 정상 owner 동작

## 세부 작업

- [ ] 등록 폼 (이름·카테고리·소개·태그)
- [ ] Server Action — `circles` INSERT + `circle_members` INSERT (`approved_by_admin=false`)
- [ ] 등록 후 사용자 마이페이지에 「申請中」 배지
- [ ] T-037 의 admin 큐에 자동 진입

## 위험·주의사항

- ⚠️ **사칭 등록 폭주** — 시즌에 사칭 동아리 폭주 가능. cooldown (같은 user 등록 횟수 제한) 추가 검토.
- ⚠️ **승인 대기 중 UI** — 사용자 혼란 방지. 「운영진 권한은 admin 승인 후 부여됩니다」 안내.

## 테스트 체크리스트

- [ ] 등록 직후 admin 큐에 표시
- [ ] 승인 전 DM 답변 시도 → 거부
- [ ] 승인 후 정상 동작
